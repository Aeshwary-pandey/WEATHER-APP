# Weather App

A Python application that retrieves current weather information for a specified city using the OpenWeather API.

## Features
- Search weather by city name
- Display temperature and feels-like temperature
- Show weather conditions, humidity, and wind speed
- Handle invalid city names and API errors
- Secure API key management using environment variables

## Technologies Used
- Python
- Requests
- OpenWeather API
- JSON
- python-dotenv

## Skills Demonstrated
- API integration
- HTTP requests and JSON handling
- Environment variable management
- Exception handling
- Input validation
- Python application development

## Usage
Run the application:


python weather.py


Enter a city name to view its current weather report.
